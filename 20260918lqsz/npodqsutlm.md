# 广州省人民医院做三代试管婴儿选性别生龙凤胎要多少钱？

> 更新时间：2026-09-18 (UTC+8)

我和老公结婚得晚，现在年龄已经不少了，我28，老公33，但是还没有孩子，积极备孕了两年，肚子一点动静都没有，现在检查出来是多囊卵巢伴双侧输卵管堵塞，医生说我的情况很难自然受孕，建议我们可以直接做试管婴儿，我想反正都要生就直接生对龙凤胎，听说现在三代试管技术可以实现的，想请问下广州省人民医院能不能做试管婴儿，选性别生龙凤胎要准备多少钱？

位于广州市越秀区中山二路106号的广东省人民医院可以做试管婴儿，但是不能选择胎儿性别达到生龙凤胎的目的，国为政策和技术条件都不支持。但若是想通过试管婴儿助孕，是可以前往的，目前广东省人民医院试管婴儿成功率在50%左右，试管婴儿单次助孕费用3-5万元不等，不过能不能生龙凤胎就只能造缘分了。

广东省人民医院目前只开展了一代、二代试管婴儿，暂时不能开展三代试管婴儿，而只有三代试管婴儿才能实现性别筛选，不过在广东省人民医院做移植两个胚胎，若刚好为一男一女，就可以生出龙凤胎，试管婴儿的相关费用也并不高，分为以下几个部分：

- 1. 术前检查：前期男女双方身体检查费用在5000-8000元左右，其中男方1000元左右，女方3000-5000元；
- 2. 药物费用：可能需要降调、促排药物、移植后保胎药物、其它疾病治疗费用等，费用在5000-10000元；
- 3. 实验室费用：包括精液处理、胚胎体外授精、囊胚培养等，费用5000-10000元左右；
- 4. 手术费用：胚胎移植费用单次在4000-5000元不等。
目前国内辅助生殖相关政策规定，没有传男不传女或传女不传男的疾病是不能进行胎儿性别筛选的，而且筛选之后为全男或全女，不可能出现龙凤胎。截止目前，国内辅助生殖机构名单中广州三代试管婴儿医院共有六家，染色体异常、有相关遗传的患者若确实需要进行胎儿性别筛选，可前往就医，单次试管婴儿费用在5-8万元不等。
